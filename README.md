# نظام ترشيح الساعات النسائية الفاخرة

## 📖 نظرة عامة

نظام ترشيح تفاعلي للساعات النسائية الفاخرة يعتمد على **المقارنة الثنائية (Pairwise Comparison)** باستخدام **خوارزمية Elo Rating** لتحديد الساعة المثالية للمستخدم بناءً على تفضيلاته الشخصية.

## ✨ المميزات

### 🎯 ثلاث مراحل ذكية

1. **أسئلة تمهيدية سريعة** (3 أسئلة)
2. **مقارنة ثنائية بصرية** (7 جولات)
3. **نتيجة مخصصة** مع تفسير مفصل

### 🎨 التصميم

- نظام ألوان فاخر
- خطوط عربية احترافية (Noto Kufi Arabic)
- تجربة مستخدم راقية
- Mobile-First Design

### 🔧 التقنيات

- HTML5
- Vanilla JavaScript
- Tailwind CSS
- Elo Rating Algorithm
